📋 Notre revendication

Le serveur MENA est victime d'une négligence flagrante. Pourtant, le MENA représente l'un des marchés les plus dynamiques du mobile gaming. Nous demandons simplement l'égalité avec les autres régions.

1
Stabilité technique — Investissements en infrastructure à la hauteur du marché MENA.
2
Égalité des événements — Même nombre d'événements, mêmes récompenses, mêmes délais.
3
Support client dédié — Équipe réactive comprenant les langues et spécificités locales.
4
Communication transparente — Calendrier de maintenance et feuille de route publique.

✍️ Signer la pétition

✅ Transparence totale — Chaque signature est publique, horodatée et vérifiable. Aucune donnée n'est cachée ni falsifiée. Le code source est ouvert et inspectable.
⚙️ Passer en mode global (obligatoire pour une vraie pétition)
Ce site utilise Firebase pour stocker les signatures en temps réel de manière transparente.
  1. Crée un projet gratuit sur console.firebase.google.com
  2. Active Realtime Database → Règles : ".read": true, ".write": true
  3. Copie ta config (⚙️ Paramètres du projet → SDK)
  4. Remplace firebaseConfig dans le code par la tienne
